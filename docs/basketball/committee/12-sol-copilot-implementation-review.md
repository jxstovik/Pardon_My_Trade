# Sol copilot implementation review — October 27, 2026

## Disposition

**Local synthetic mock: usable for rehearsal. Coach: usable for explicit advisory ingestion. Fantrax live feed and every Fantrax write mode: not ready.** The implemented `fantrax-dom.ts` decoder verifies only the empty pre-draft grid; it deliberately refuses live inference. There is no verified live selected-pick history, stable identity crosswalk, active clock/turn capture, or Fantrax actor. The local simulator's receipt proves its own action path only. This is a source review; root owns the compiled tests and browser evidence.

## Findings resolved during review

- **Last-good state cannot authorize a mock pick after pause, rejection, or age expiry.** `draft-browser-actor.ts:35-68` checks ready status, pause, complete history, identity, board and session scope, source and receipt age, turn, expiry, and a 15-second clock buffer. `draft-observer.ts:137-153` now carries pause across accepted refreshes. The Coach route persists rejected observations as blocked while retaining historical picks (`copilot-server.ts:501-515`). Its advice overlay computes age on every read, including cache hits, and clears actionable recommendations/own-turn for blocked, paused, and stale state (`copilot-server.ts:240-286`). Mock GET captures the simulator's own current board while decrementing the same turn's clock; Coach GET does not renew external evidence (`copilot-server.ts:450-461`).
- **Journal partial-publication failure fails closed.** `draft-journal.ts:143-180` poisons the writer after any event/current-file write failure, so a later append cannot reason from an older in-memory head. The journal replays the durable JSONL history on reopen. The reviewer-requested post-append failure test is in `basketball-observer.test.ts:270-281`.
- **Recommendation identity, clock, slot, and lineup comparison now match their data.** The UI reads nested recommendation players (`app.js:53-56`), displays a decaying observed clock (`app.js:276-284`), and shows profile advice before generic available rows. The mock server checks the chosen slot against an explicit legal assignment before confirmation (`copilot-server.ts:100-135,389-410`). The adaptive lineup selector maximizes the same shared eight-category team metric it reports, subject to legal G/F-C/Flx assignments (`draft-adaptive.ts:176-275`); root added brute-force equivalence coverage. Off-turn scenarios now simulate opponents before the first own pick and exclude players consumed in that prefix (`draft-adaptive.ts:600-618`).

## Remaining limits and operational risks

- **Live correction evidence remains unproven.** `draft-observer.ts:206-216` accepts a changed historical pick when an input carries `correction:true`; the Coach endpoint accepts an explicitly submitted observation. That is sufficient for a local advisory correction but does not independently prove a Fantrax commissioner undo. A future live feed needs a fresh complete browser history, stable player-ID evidence, and an audit link between superseded and new revisions before treating such a correction as platform authority.
- **An abrupt crash leaves the exclusive journal lease behind.** `draft-journal.ts:91-100` intentionally fails closed on a leftover `.writer-lease`. Recovery during a draft requires an operator to verify the former process has stopped and safely clear the lease before replay. A documented, tested recovery procedure would reduce downtime; do not steal a lease by age alone.
- **The forecast and opponent paths are explicitly heuristic.** Bounded working pools, deterministic ADP/guard/big opponent scenarios, and partial forecast coverage support comparisons, not calibrated survival or win probabilities. Source retrieval age is not publication age. High-priority omitted players and current status evidence still need curation before real-league use. The plan's supported browser bridge, complete live history, identity, and timing gates have not passed.

The final source check found no new local-mode blocker. `sourceAgeSeconds` now uses the source capture time (`copilot-server.ts:309`), with a 10-second-before-receipt regression assertion. The UI renders the clock from that capture time, labels expiry, discards older server responses, and binds render timing to the specific clicked action (`app.js:253-258,286-292,321-339`). `ingest-fantrax-preflight.mjs:1-26` is a loopback-only, read-bootstrap helper: it decodes a previously captured empty Fantrax grid and posts it to an explicit Coach server; it makes no Fantrax HTTP call or platform write.

Root reports a fresh 55/55 compiled test pass, three earlier complete browser-driven synthetic drafts (336 selections, 42 own picks), and a final two-own-pick smoke after the last UI/instrumentation edits. That smoke also rejected an expired-clock confirmation without advancing the board and retained pause through reload. A fresh real pre-draft capture reached Coach with about 13.6 seconds of manual browser-to-receipt delay; this is evidence for bootstrap only and misses the proposed three-second live bridge target. The Fantrax mock lobby still offered no usable draft at the latest check. These results support local rehearsal and explicit Coach, while Fantrax live ingestion and all real writers remain unvalidated and disabled.
